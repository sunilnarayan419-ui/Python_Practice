# 🐍 Python Practice

This repository contains my **Python practice problems and small exercises** while learning Python.

The main purpose of this repository is to improve my:

- Python syntax
- Programming fundamentals
- Logical thinking
- Problem-solving skills
- Debugging ability
- Coding workflow
- Confidence with Python

This is **not a DSA-focused repository**. The goal is simply to learn Python by writing and practicing code regularly.

## 🎯 Why This Repository?

Instead of only learning Python through tutorials and theory, I am using this repository to practice concepts by actually writing programs.

The focus is:

> **Learn → Practice → Debug → Improve**

I will gradually add more problems and exercises as I learn new concepts.

## 📚 What I Am Practicing

Currently, the repository mainly contains beginner-level Python problems and exercises involving concepts such as:

- Variables
- Data types
- Operators
- Input and output
- Conditional statements
- Loops
- Basic functions
- Strings
- Lists
- Dictionaries
- Other Python fundamentals

More concepts will be added as I progress.

## 📈 Progress

This repository is a **work in progress**.

I am intentionally starting with simple problems and gradually increasing the difficulty as my understanding improves.

There is no fixed problem list or predefined curriculum here. The repository will grow naturally along with my Python learning journey.

## 💡 Learning Approach

For each problem, I try to:

1. Understand the problem
2. Think about the logic
3. Write the Python code
4. Run and test it
5. Find and fix errors
6. Improve the solution when possible

The goal is not just to get the correct output, but to become more comfortable with **writing Python independently**.
